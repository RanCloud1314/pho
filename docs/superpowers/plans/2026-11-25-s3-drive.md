# S3 存储后端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Pho 新增泛 S3 协议存储后端（AWS/R2/OSS/COS/MinIO），完整接入上传/下载/增量同步/Range 流播。

**Architecture:** 按既有 drive 模式分层新增：`server/drive/s3/` 实现 `StorageDrive` 接口（ListObjectsV2 delimiter 模拟目录），proto 加 `SetDriveS3` RPC，`server/api/s3.go` 处理器，Flutter `s3form.dart` 表单。目录树 `YYYY/MM/DD` 以 key 前缀表达，上层（imgmanager/RangeByDate/FilterNotUploaded）零改动。

**Tech Stack:** Go + aws-sdk-go-v2 (`aws-sdk-go-v2/config`, `service/s3`, `feature/s3/manager`)；Flutter/Dart（grpc + shared_preferences）；测试用 MinIO Docker 容器 + testify/suite。

**Spec:** `docs/superpowers/specs/2026-11-25-s3-drive-design.md`

## Global Constraints

- 响应包络统一 `bool Success + string Message`，错误时 `return nil` error（不返回 gRPC error）——对齐 `server/api/webdav.go`
- key 拼接统一用 `path.Join`（`path` 包，非 `filepath`），禁止 Windows 反斜杠进入 S3 key
- key 为相对路径（无前导 `/`），对齐 WebDAV drive 收到的 genPath 输出
- gomobile 兼容：SDK 必须纯 Go；构建 `CGO_ENABLED=0`
- 测试顺序执行：`go test -v ./server/... -p 1 -failfast`，需要 Docker
- Dart 侧 prefs 键名：`s3_endpoint`, `s3_region`, `s3_access_key_id`, `s3_secret_access_key`, `s3_bucket`, `s3_path_style`, `s3_root`；"drive" prefs 值为 `"S3"`
- proto 改动须 `make protobuf` 同时再生成 Go 与 Dart stub（Makefile 已配置）

## Review Focus

1. **共享 bucket 前缀**：Root 非空时所有上传/列举/删除 key 都带 `root/` 前缀，且 IsExist/FilterNotUploaded 不串到前缀外的对象 — Task 2 测试覆盖
2. **Windows key 分隔符**：drive 跑在用户手机上无此问题，但单元构造路径时若用 filepath.Join 会产出 `\` key — Task 2 用含多级路径的断言覆盖
3. **ListObjectsV2 分页**：>1000 对象时 Range 必须翻页遍历完 — Task 2 覆盖（写入 1001 个空对象成本高，改为将分页大小通过包内可配置变量 `listPageSize` 设小来测）
4. **Range 流播**：DownloadWithOffset 正确带 `Range: bytes=offset-` 且 offset=0 与普通 Download 等价 — Task 2/3 覆盖
5. **连接失败反馈**：错误 endpoint/错误凭证时 SetDriveS3 返回 `Success=false` 和可读 Message，且不把坏 drive 装进 ImgManager — Task 3 覆盖

- [ ] **Step 4: 引依赖并实现 `s3.go`**

`go get github.com/aws/aws-sdk-go-v2/config github.com/aws/aws-sdk-go-v2/service/s3 github.com/aws/aws-sdk-go-v2/feature/s3/manager github.com/aws/aws-sdk-go-v2`

实现要点（结构见 spec）：
- 构造：`config.LoadDefaultConfig(ctx, config.WithRegion(region), config.WithCredentialsProvider(credentials.NewStaticCredentialsProvider(ak, sk, "")))`；endpoint 非空再叠 `config.WithBaseEndpoint(endpoint)`；`s3.NewFromConfig(cfg, func(o *s3.Options){ if pathStyle { o.UsePathStyle = true } })`
- Upload：`manager.NewUploader(cli).Upload(ctx, &s3.PutObjectInput{Bucket, Key, Body: r})`，defer r.Close()
- IsExist：HeadObject，`NotFound` 错误码 → `(false, nil)`
- Download/DownloadWithOffset：GetObject，后者设 `Range: aws.String(fmt.Sprintf("bytes=%d-", offset))`
- Range：循环 ListObjectsV2Pages，Prefix=`path.Join(root, dir)`（dir 已含尾部处理则照 WebDAV 的形式对齐），Delimiter=`/`；Contents → FileInfo{IsDir:false, Name: 去掉 Prefix 后的相对名, Size, LastModified}；CommonPrefixes → FileInfo{IsDir:true, Name: 去掉 Prefix 的相对名（保留尾部 `/`，与 WebDAV 一致）}；deal 返回 false 时中断
- 过滤 S3 伪目录 key（以 `/` 结尾的 Contents 条目，跳过）
- 关键路径用 `path.Join`；`listPageSize > 0` 时设 `o.PageSize`
